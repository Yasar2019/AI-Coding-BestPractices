# Common Mistakes in Prompt Engineering

**Last updated:** 2025-12-19

1. **Ambiguity**
   - **Mistake:** Writing vague prompts like “Tell me about AI.”
   - **Fix:** Be specific about scope, audience, and output format.

2. **Overloading the Prompt**
   - **Mistake:** Asking for multiple unrelated tasks at once.
   - **Fix:** Split into smaller prompts or multi-step instructions.

3. **No Constraints**
   - **Mistake:** Not defining length, format, or style.
   - **Fix:** Add explicit constraints (e.g., JSON, bullet list, word count).

4. **Skipping Verification**
   - **Mistake:** Treating AI output as authoritative.
   - **Fix:** Validate with tests and official documentation.

5. **Sharing Sensitive Data**
   - **Mistake:** Pasting secrets or private data into prompts.
   - **Fix:** Redact or use synthetic examples.
