Check 02 · Verification engineering

A generated patch passes one happy-path test. What is the best next action?

Merge it because the test is green.
Add boundary and failure-path tests derived from the specification, run them, then inspect the diff.

Select an answer.

Check 03 · Agentic debugging

What should an agent do before editing a failing function?

Reproduce the failure and state a falsifiable hypothesis about the causal code path.
Refactor the function first to make it easier to reason about.
Generate multiple patches and pick the cleanest-looking one.
